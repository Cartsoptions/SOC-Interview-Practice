# SOC Interview Practice

Daily SOC analyst interview preparation focused on **real-world, job-based answers rather than textbook definitions**.

## Purpose

This repository documents my continuous preparation for SOC Analyst and Junior Cybersecurity Analyst interviews. Each entry focuses on how security concepts are actually used in day-to-day SOC operations, including investigation steps, relevant logs, tools, escalation decisions, and realistic scenarios.

## Daily Practice Format

Each day contains **3 SOC interview questions**. Every answer is structured around:

- What the concept means in a SOC environment
- How it is used on the job
- A realistic security scenario
- What a Tier 1 SOC analyst would investigate or do
- Relevant logs, tools, and evidence sources
- A concise interview-ready takeaway

## Topics Covered

- SIEM monitoring and alert triage
- Windows and Linux logs
- Networking and firewalls
- Phishing and email security
- Endpoint Detection and Response (EDR)
- Incident response
- Active Directory and authentication
- MITRE ATT&CK
- Threat intelligence
- Malware and ransomware
- SOC escalation and documentation
- Scenario-based investigations

## Goal

The goal is not to memorise definitions. It is to develop the ability to explain security concepts the way a SOC analyst would encounter, investigate, and respond to them in a real working environment.
